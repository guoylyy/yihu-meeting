# 会议与纪要 使用说明

## 谁该用

- 经常开会、会后要出纪要的负责人和项目经理
- 手上有一堆纪要文件，想按项目归好类、把决议和待办理出来的人
- 被拉进会议、想快速看「定了什么、我要做什么」的参与人

## 三步上手

1. **导入**：点列表页右上角的「导入」，上传文件或粘贴文字。一次最多 5 个文件
2. **核对**：AI 会识别标题、时间、地点、主持人、参会人、项目和摘要，并整理出决议、待办、风险、下次议题。项目不对，在结果那一行直接改
3. **跟进**：打开会议，给待办点「指派」填负责人和截止日；需要别人看到，就在「编辑」里加参与人

## 导入格式

| 来源 | 要求 | 说明 |
|---|---|---|
| 粘贴文字 | 最多 5 万字 | 任何来源的文字都可以 |
| Word `.docx` | 单个 ≤10MB | 读正文和表格；图片里的字读不了。老版 `.doc` 请先另存为 `.docx` |
| PDF `.pdf` | 单个 ≤10MB | 要带文字层，只读前 60 页。扫描件读不了，请粘贴文本 |
| 文本 `.txt` `.md` | 单个 ≤10MB | UTF-8 或 GBK 编码都可以 |
| 图片 `.png` `.jpg` | 暂未开通 | 图片识别暂未开通，请先转成文字 |

内容超过 5 万字时只保留前面部分，页面会提示。

## 常见问题

**提示「自动整理失败，可手动填写」？**
模型这次没有返回可用结果。原文已经保存，会议也建好了。打开会议可以手动填，也可以点「用 AI 提炼」再试一次。

**提示「这是扫描件」？**
PDF 里只有图片没有文字层，目前读不了。用 Word 或 WPS 转成文字后再导入，或者把文字粘贴进来。

**AI 识别出的参会人能看到这场会吗？**
不能。识别出的姓名只做记录。能看到会议的只有创建者和「参与人」里选的人。可以在「设置」里配默认参与人。

**没写开会时间的记录怎么办？**
先按导入时间记，结果行会提示，到会议的「编辑」里改。

**重新提炼会覆盖我改过的内容吗？**
标题、时间、已填的地点、主持人和项目不会动。决议、待办、风险、下次议题这四块会整批替换，手动补的也会被替换，所以提炼前会先确认。

**指派后对方会收到通知吗？**
不会。指派只记录负责人和截止日。要进别人的待办，点待办右侧的 ⋯，选「复制」，粘到收件箱。

**设置改了要重启吗？**
不用，下一次操作就生效。设置只影响你自己。

**模型能换吗？**
平台托管时由平台统一配置，在平台的「管理 → 模型与 AI」里改。
